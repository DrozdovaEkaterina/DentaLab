# DentaLab

Учебный стоматологический 3D-тренажёр для ПК. Версия 0.3.1 — первый интерактивный случай кариеса на моляре из предоставленной пользователем модели рта.

**Статус: технический учебный прототип, медицинская валидация не выполнена.** Реконструированные ткани, приблизительный масштаб и алгоритмы оценки требуют проверки стоматологом-преподавателем. Проект не подтверждает клиническую компетентность.

## Запуск

Нужен актуальный браузер с WebGL 2. Установка npm-пакетов не требуется:

```sh
python3 -m http.server 8787 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8787. Через `file://` ES-модули и загрузка модели не работают. Все зависимости включены локально. После успешного заполнения кэша сайт может открываться офлайн; первоначальная загрузка нужна по HTTP/HTTPS.

## Реализовано

- Исходная GLB-модель всей полости рта, вращение и масштабирование.
- Моляр выделен по связности из общей сетки исходных зубов, а не заменён произвольной формой. Изменения рабочего зуба отображаются и в полости рта.
- Объёмная сетка 49 × 76 × 69 с шагом 0,25 условного мм. Поверхность строится алгоритмом surface nets в Web Worker.
- Коронка из исходной модели; реконструированные два расходящихся корня, эмаль, дентин, пульпа и каналы; заданное объёмное поражение.
- Процедурные физические материалы с оттенками эмали, дентина и цемента, микрорельефом, влажными бликами и локальным студийным освещением. Корни видны по умолчанию.
- Сферический и цилиндрический рабочие наконечники с контролем питания, диаметра, оси и глубины. Наклон меняет геометрический контакт, без выдуманного универсального углового штрафа.
- Автоматический наклон и поворот по положению мыши на зубе. Каждая ось фиксируется отдельно, после фиксации доступна ручная настройка. Значения и фиксации сохраняются локально.
- Пояснения 11 терминов с локальными SVG-схемами по наведению, фокусу и нажатию.
- Пошаговый помощник случая 01 со стрелками к 3D-объектам и элементам управления; его можно отключить. В самостоятельной практике стрелки скрыты.
- Плотное прилегание тонкого коффердама по контуру шейки зуба.
- Сообщения о влиянии охлаждения, питания, изоляции, фиксаций и режимов отображения.
- Непрерывная траектория со swept sampling; начальная подача проходит путь от поверхности, а не телепортируется внутрь зуба.
- Удаление ткани меняет настоящий объём и поверхность. Здоровые ткани и пульпу можно повредить.
- Учебное внесение композита в удалённый объём, условная полимеризация и финирование материала.
- Карта вымышленного случая справа над текущим этапом; пошаговые клинические объяснения, подтверждение изоляции, учебный разрез и подсветка поражения.
- Отдельная кнопка «Начать сначала», выделенная рамкой отмена, показатели объёма удалённых поражённых и здоровых тканей.
- Самостоятельная практика без разреза, подсветки и текущего процента поражения.
- Отмена действий, локальное автосохранение, экспорт/импорт прогресса и отчёта.
- База знаний со ссылками на российскую вузовскую программу и международные рекомендации.

## Управление

| Действие | Управление |
| --- | --- |
| Вращение | Правая кнопка мыши; в режиме осмотра также левая |
| Масштаб | Колесо |
| Выбор инструментов | 1–6 |
| Питание | Space или кнопка на панели |
| Работа | Удерживать ЛКМ над зубом |
| Глубина подачи | Ползунок, W/S или Shift + колесо |
| Наклон | Автоматически вслед за мышью; после фиксации — ползунок или A/D |
| Поворот оси | Автоматически вслед за мышью; после фиксации — ползунок |
| Отмена | Ctrl/⌘ + Z |

Перед вмешательством откройте карту случая, примите учебный план и подтвердите изоляцию. Подача измеряется вдоль оси инструмента от **исходной** поверхности; после удаления ткани увеличивайте её постепенно.

## Данные и приватность

Прогресс хранится в localStorage под ключом `dentalab.caries.v1`. Объёмные изменения, показатели и этап остаются в браузере. IndexedDB, внешние API, аналитика и серверная БД не используются. Включённый service worker кэширует ресурсы приложения на том же origin. Прогресс в GitHub не отправляется. Внешние источники открываются только при переходе пользователя по ссылке.

Очистка данных браузера удалит сохранение. Для переноса используйте меню «Сохранения и экспорт». Импорт проверяет версию, размеры, допустимые изменения и числовые показатели; ошибочный файл не меняет текущую модель.

## Проверка

Тесты используют встроенный Node.js test runner, Node.js 20+:

```sh
npm test
npm run check
```

Проверяется выключенное питание, геометрия контакта, влияние наклона и глубины, непрерывная траектория, повреждение пульпы, восстановление, сериализация и валидация импорта. Дополнительно сценарий проверяется в Chrome вручную.

Для воспроизводимой подготовки объёма (только стандартная библиотека Python):

```sh
python3 tools/prepare_model.py
```

## Что ещё требуется

Замена старой пломбы, хирургия горизонтального третьего моляра и восстановление скола **не реализованы**: они обозначены как последующие сценарии. В первом случае пока не моделируются истинный нагрев и усилие, мягкая деформация, кровотечение, анестезия, диагностика по клиническим изображениям, адгезивный протокол, послойная реставрация, окклюзия и биологическое заживление.

Полимеризация за 5 секунд — интерфейсная демонстрация, **не инструкция по лечению**. Охлаждение протоколируется; достоверная тепловая модель отсутствует. Миллиметровые значения нормализованы из внешней модели, а не измерены на реальном пациенте. Процент поражения — техническая характеристика заданного объёма, не клинический критерий «удалить всё».

См. [план клинической проверки](docs/CLINICAL_REVIEW.md), [источники](docs/SOURCES.md) и [атрибуцию](ATTRIBUTION.md).
